# WFN X Growth Content Log

The authoritative, git-tracked record of every post written for @wfnglobal's
X growth content (the 14-day-cycle batches and the "Weeks" calendar). This
file exists so no future run — scheduled or ad hoc — has to round-trip to the
external Claude Docs calendar (https://claude.ai/artifact/2vDrEDpjMJCYeb1ZE8qiEK)
just to check what's already been used. It is the repo's mirror of that doc.

**Rule: before writing any new X growth post, read this file in full and
never reuse a topic, an opening line or a KJV verse reference listed here.
Then check every verse you plan to use against everything else already
published:** `grep -rlF "Psalm 112:7" app social articles library`
(one grep per reference). Any hit means pick another verse. After writing
new posts: (1) append them here in the same table format, (2) also add them
to the Claude Docs calendar doc so Oladapo's copy stays in sync, and
(3) commit this file with the new batch.
